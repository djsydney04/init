# Init identity

Init uses a compact lowercase **i** built from two rounded server blocks. Two broad slots suggest hosted services. The upright silhouette replaces the former Bit mascot and keeps the mark legible in small navigation and app icons. The name stays as live text beside it.

- Master transparent PNG: [`assets/init-bit.png`](../assets/init-bit.png), 1254 × 1254. The asset name is retained so existing browser and desktop references keep working.
- Desktop exports: [`desktop/icons/init-bit.png`](../desktop/icons/init-bit.png), 512 × 512, and [`desktop/icons/init-bit.icns`](../desktop/icons/init-bit.icns), containing 16–1024 pixel representations.
- The mark uses warm off-white `#F2EFE8` and charcoal `#2A2A29`. Keep its aspect ratio and transparent background; do not reintroduce the mint accent, face, or sparkle.
- The console uses the same symbol in the sidebar, deployment dialog, and browser icon. Decorative images have empty alternative text because the adjacent text supplies the name.

The app palette uses charcoal surfaces and warm off-white text and actions. The light theme reverses their roles. CPU and memory charts use different neutral tones; network receive/send also differ in line style and retain their directional labels. Status labels remain explicit so meaning does not depend on color.

Created with the built-in image generation tool. The master artwork's alpha was preserved. Desktop sizes were derived with macOS `sips` and `iconutil`.

Widen the dot and body approximately 20% relative to their height for a sturdier app-icon silhouette, keep them exactly aligned and centered. Crisp vector-like edges with clean anti-aliasing only. Background must be genuinely transparent with no colored edge fringe. No surrounding app tile, no face, no sparkles, no additional marks, no text. Deliver a single final production logo symbol, not a mockup.
