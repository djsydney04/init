# Bit, the Init mascot

Bit is a cheerful mint server with a little startup spark. The name stays as live text beside the mark so it remains sharp and accessible.

- Original transparent logo: [`assets/init-bit.png`](../assets/init-bit.png), 1254 × 1254.
- Desktop packaging: [`desktop/icons/init-bit.png`](../desktop/icons/init-bit.png), 512 × 512, and [`desktop/icons/init-bit.icns`](../desktop/icons/init-bit.icns).
- The console uses the mark in its sidebar, deployment dialog, and browser icon. Decorative instances have empty alternative text; the adjacent text provides the name.
- Mint `#9bd8c2` and charcoal `#252525` are the logo's intended palette. Keep the mark upright and preserve its aspect ratio and transparent background.

Created with the built-in image generation tool. The PNG and ICNS packaging sizes were derived with macOS `sips` and `iconutil`; the generated artwork was otherwise preserved.
