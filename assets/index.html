      Tailscale
      Optional private network
      Reach your Linux machines and Macs by private name, at home or away. Use ordinary SSH over Tailscale.
      Install Tailscale ↗
      Checks the Tailscale app on this computer. Does not change network settings or access rules.
      Set up Tailscale and SSH
      1. Install Tailscale on this computer and the destination, then sign in to the same tailnet.
      2. Enable Remote Login on a Mac, or OpenSSH on Linux. Allow SSH between these machines in your tailnet access rules.
      3. Connect once with ssh your-user@your-machine, verify the host key, and configure an SSH key or agent for connections without prompts.
      4. On the destination, install Init and run init init --discover then init serve.
      5. Find the machine below, save its SSH connection, and choose Test connection.
      Full setup and troubleshooting ↗
      
    
      Add a machine
      Use a LAN address, Tailscale name or an alias from your SSH config. Keys stay in your SSH agent or SSH config.
      Saves this connection on the computer running the dashboard. It does not install anything or start remote services.
      
      
      One-time setup
      1. Install Init and start its controller on the destination. Keep it running to schedule jobs.
      2. Enable SSH on that machine. On macOS, turn on Remote Login; on Linux, use OpenSSH.
      3. Connect once from Terminal, verify the host fingerprint, and make sure your SSH key works without a password prompt.
      4. Save and test the connection here, then open its services.
      Each machine keeps its own workspaces, limits and schedules. Init stays on loopback; SSH forwards requests without opening a dashboard port. A tested connection is checked again when used.
